# 参数化监控与 Console

交换核心及 GMII/MII/RMII wrapper 新增统一只读 CSR 和真实 PHY 状态输入，保留
原 `stat_o` 的 32 位调度统计语义。地址、字段及握手详见 [完整 ABI](monitor.md)，
常量位于 `rtl/es_defs.sv`。集成者必须连接新增输入；没有 PHY 管理时状态接零表示
未知，不使用 CSR 时请求和地址接零。

`REFRESH_INTERVAL_MS` 默认 500，必须大于零。采样周期由 `CLK_FREQ_HZ` 换算并向上
取整到时钟。累计计数为 64 位；每秒包数、bit/s 均按实际采样周期换算，不能直接把
半秒计数当作每秒计数。多周期计算结束后原子发布，首个完整窗口完成前数据无效。
若配置周期短于计算所需时间，下一次采样会等待计算完成，实际窗口仍会正确报告。

RX 统计通过校验及过滤的帧，TX 统计最后一个 FCS 八位组发送完成的帧；字节统计
包含 MAC 头与数据，TX 包含补齐字节，排除前导码、FCS 和帧间隔。发送完成仅代表
本地 MAC 完成序列化，不代表对端收到。RX/TX 利用率分别以有效帧 bit/s 除以实际
链路容量计算，单位千分比。队列占用和峰值的单位为 64 位数据节拍；另有矩阵忙碌
比例、运行秒数、MAC 表占用和累计清表次数。未知/断链时利用率为零，必须结合
PHY 有效和链路位解释。

MAC 按索引逐项读取，单个表项的四个 32 位字保持一致；学习、老化、替换无需暂停。
整表遍历为实时视图，串口附带开始/结束时钟及清表代数，不保证整表原子性。
MAC 列表是尚未失效的学习记录，不是在线设备清单；老化仍默认关闭。

串口参数默认 115200、8 数据位、无校验、1 停止位、无流控。UART 模块支持
5–8 位、None/Odd/Even 校验、1/2 停止位、None/RTS_CTS 流控；ASCII Console
只支持 7/8 位。RTS/CTS 为低有效，CTS 仅在字符之间暂停发送。参数为编译期参数，
不支持的组合、过低时钟或超过 2% 的整数分频误差会在 elaboration 时失败。

命令为 `help`、`status`、`port <n>`、`mac all`、`mac <n>`，端口编号从零开始。
支持 CR/LF/CRLF。输出值为带 `0x` 的十六进制整数，字段名说明单位；每条统计命令
固定一份快照。一次处理一条命令，超长、非法、忙时输入均有诊断。串口校验、帧格式、
溢出及输入错误分别计数。没有流控的上位机应等待完整响应后再发送下一条命令。

DE2-115 的按键、LED、LCD 及数码管操作见
[板级说明](../board/de2_115/quartus_ii/README.md)。`make monitor` 可运行新增自检，
也已纳入 `make unit`。仿真证明的转发行为不变不等同于 FPGA 时序已闭合。

2026-11-05 本地工具链检查、lint、RTL 编译、unit、param、MII/RMII 和主回归均通过，
四个顶层的完整 Yosys 综合通过。主回归 158 项检查为零错误，与修改前的十五个阶段
时间戳和结束时刻一致。另有 14 组非法参数、六项 CAM 表项的非二次幂配置、六种
UART 模式及 17 项 Console 端到端检查；CTS 暂停不会冻结显示刷新。

默认参数下，通用 Yosys 单元数在三个核心 wrapper 中增加约 19.4%，DE2-115 顶层
增加约 62.4%（包含新增串口、LCD、PHY 管理和显示逻辑）。这些不是 FPGA LUT 数，
也不能证明最高频率。Quartus 因 Remote Desktop 许可证限制报错 292032，尚未完成
Fitter、资源占用、时序、GDS 和实板验证。详细资源数值与验证记录见[完整说明](monitor.md)。
